# Markda 0.2 ✨

This release makes everyday writing feel faster and safer.

## Added

- Live tables with direct cell editing
- Document statistics and reading time
- Light and dark editor themes

## Improved

- **Undo** now keeps your place in long documents
- Saving no longer interrupts the active editor
- Markdown source is preserved more faithfully

## Fixed

- ~~Occasional cursor jumps~~
- Extra line breaks in editable code blocks

`Ctrl+S` saves. `Ctrl+Z` takes you back.
