# Markda

> **Write Markdown in its rendered form. Keep the source exactly yours.**

Markda is a calm, source-preserving Markdown editor for **VS Code Desktop**. Edit a polished document in place, then switch to its ordinary, portable Markdown source at any time.

## Markdown, alive

| Create directly | Stay in control |
| --- | --- |
| **Headings**, *emphasis*, links, lists, and quotes | Source mode, unified undo/redo, and local rendering |
| Tables, task lists, code, math, diagrams, and images | Focus mode, typewriter mode, outline, and search |

- [x] Edit rendered Markdown without leaving VS Code
- [x] Keep untouched source text and syntax intact

Inline math stays natural—$E = mc^2$—and equations remain beautifully readable:

$$
e^{i\pi}+1=0
$$

`const idea = "formatted to read, plain text to keep";`
