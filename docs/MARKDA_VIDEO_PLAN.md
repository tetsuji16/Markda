# Markda short video plan

## Goal

Turn the first impression of Markda into one clear promise: **edit Markdown as a rendered document while keeping the source portable**.

## Deliverable

`media/videos/markda-intro.mp4` is a 16-second, 1280×720 MP4 suitable for the README, VS Code Marketplace media, GitHub posts, and a first social post. It uses the product screenshot as the proof point and keeps all messaging readable without audio.

## Storyboard

| Time | Message | Visual |
| --- | --- | --- |
| 0–4 s | Markdown, alive. | Markda rendered document with gentle zoom |
| 4–9 s | Edit the rendered form; keep the source exactly yours. | Live editor screenshot |
| 9–13 s | Math, tables, code, tasks; Focus, Typewriter, local rendering. | Feature callouts |
| 13–16 s | No telemetry. Try Markda on GitHub. | CTA and repository URL |

## Publishing sequence

1. Add the MP4 to the GitHub README or a release post alongside the showcase image.
2. Attach the same clip to the Marketplace listing if the listing surface accepts video; keep the README image as the fallback preview.
3. Publish a captioned social cut with this copy: “Write Markdown in its rendered form. Keep the source exactly yours. Meet Markda for VS Code Desktop.”
4. Link every post to `https://github.com/tetsuji16/Markda` and measure repository visits, installs, and stars for seven days.

## Next iteration

Create 9:16 and 1:1 crops, add optional music or voice-over, and A/B test “source-preserving” against “Markdown, alive” as the opening hook.
